Car Brand Website

A responsive landing page for a car brand, showcasing modern web design using HTML and CSS.

Features

- Responsive Layout: Adapts seamlessly to desktop, tablet, and mobile devices.
- Clean Design: Utilizes modern CSS for visually appealing aesthetics.
- Easy Customization: Straightforward structure to easily update content and styles.
- Showcase Sections: Dedicated areas for car models, brand highlights, contact info, and more.

Technologies Used

- HTML (52.1%)  
  Structuring the web pages and content.
- CSS (47.9%)  
  Styling, layout, and responsiveness.

Getting Started

1. Clone the repository:
   bash
   git clone https://github.com/FiraolTsegaye/Car-brand-website.git
   cd Car-brand-website
   
2. Open `index.html` in your browser to view the website.

Customization

- Edit text, images, and content in `index.html`.
- Modify design and layout in `style.css` (or other CSS files).

Project Structure
